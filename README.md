# Мамулин обед – прототип главного экрана

## О проекте
Прототип главного экрана аркадной игры-кликера.  
Игрок кормит маму, кликая на падающую еду. Полезная еда увеличивает счётчик «Накормлено», вредная заполняет шкалу «Ожирение». При 10 единицах вредной еды игра заканчивается и предлагает перезапуск.

**Реализовано:**
- Анимированное падение продуктов (овощи, фрукты, бургеры, пицца)
- Кликабельность еды с эффектом «Ням!» и изменением счётчиков
- Шкала ожирения
- Правый блок меню с кнопками «Играть», «Настройки», «О проекте» на основе Kenney UI ассетов
- Модальные окна с информацией и переключателем отображения вредной еды

## Стек технологий
- JavaScript
- Phaser 3
- Vite
- HTML/CSS
- Kenney UI assets (кнопки)

Как ИИ помог в разработке
Задание выполнено с активным использованием ИИ-ассистента (ChatGPT/DeepSeek).
ИИ использовался на всех этапах:

Формулировка концепции – ИИ предложил идею игры про кормление мамы с механикой: полезная еда увеличивает счётчик накормленного, вредная – шкалу ожирения, при достижении лимита игра заканчивается.

Генерация кода – ИИ написал сцену на Phaser: фон, персонаж матери (геометрическими фигурами), падающие объекты с эмодзи еды, обработку кликов и столкновений, счётчики, шкалу ожирения, условия завершения.

Отладка и исправление ошибок – возникали проблемы: текст не влезал в кнопки, модальные окна не перекрывали меню, еда не кликалась. ИИ последовательно предлагал исправления (увеличение кнопок, настройка depth, fallback-отрисовка).

Сборка и деплой – ИИ составил инструкции по установке Node.js, запуску через npm, созданию репозитория на GitHub и заполнению отчёта.
